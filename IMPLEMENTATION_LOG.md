- 2026-11-04 Sample Superhero Series S02E16 ASS timing regression: reproduced the production remux size within 32 bytes and confirmed the old `PREV_OUTPTS+1` clamp artificially advanced equal-timestamp subtitle packets, making packet 506 appear +0.501 s and later packets up to +3.041 s from the source. The validator math matched the output, but the clamp created the drift; it was not evidence of source A/V subtitle desynchronization. V15 now clamps only backward PTS/DTS and preserves equal timestamps. A real-file test remux kept all 84,323 payload hashes and reported zero packet movement. Full local suite: 163/163 passed. See `SUBTITLE_MUX_TEST_REPORT.md`.
- 2026-11-04 four-movie log review: confirmed all four failures emitted `[Failure notification] Sent.` The Spider-Man SAR rejection is a validator bug: the source has no SAR/DAR, while a 20-second Arc output keeps 1920×1040 with SAR 1:1. The Batman's FFprobe scan hit the old four-hour absolute deadline; process scans now have a 12-hour maximum with a 30-minute no-output timeout. - 2026-11-05 HDR hybrid and audio timestamp repair: added a metadata preflight for unsupported DV/HDR10+ hybrids and a narrowly verified single-layer DV 8.1/HDR10-compatible base route. - 2026-11-05 CPU decode threading: benchmark results established that FFprobe's one-thread default left source scans CPU-bound. The shared `TDARR_DECODE_THREADS` setting now defaults to 4 (valid 1–16), with `TDARR_PRECHECK_THREADS` accepted as a compatibility alias. It covers source and candidate frame scans, retained source and candidate audio decodes, CPU hybrid encode inputs, source decode fallback, the extra-video probe, HDR frame probes, and the frame-count fallback. Arc QSV encode and hardware video decode remain unchanged; packet-only timeline scans and stream-copy operations do not receive decoder thread flags. The 1/2/4-thread benchmark returned identical frame reports on a 2,878-frame 1080p H.264 excerpt, a 508-frame 4K HEVC HDR10+ sample, and a 2,878-frame 1080p AV1 output excerpt. Four threads took 6.352 s vs 18.181 s (H.264), 11.528 s vs 35.033 s (HEVC), and 7.328 s vs 16.168 s (AV1). The test container’s stale Tdarr flow was not run. Details: `PRECHECK_THREAD_BENCHMARK_2026-11-05.md`.
- 2026-11-05 TrueHD timestamp guard: the Sample Feature Film production log showed a false audio-guard failure because 1.5 million equal DTS pairs on a 1 ms Matroska time base were accumulated as 1.5 million required repair ticks. The full scan showed zero backwards steps, and a 10-second remux with the flow's timestamp-related mux flags preserved all 11,999 packets (including 1,999 equal-DTS transitions) with no warnings. The analyzer now skips repair for equal-only streams while preserving the existing strict bounded repair for actual backwards DTS. A non-strict repair experiment was rejected after it created repeated timestamp diagnostics on the known Sample Feature Film regression sample. The updated export is local and remains unimported; details and limits are in `HDR_AUDIO_REPAIR_TEST_REPORT.md`.
